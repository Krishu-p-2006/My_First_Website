About

From C basics to building things that help other students.

I'm a second-year BCA student figuring out placement prep on my own — and writing down what I learn along the way.

I'm currently in my second year of BCA at Shri Ram PG College of Commerce & Education, affiliated with Mahatma Gandhi Kashi Vidyapith (MGKVP), Varanasi. My college doesn't run campus placements, so early on I decided that wasn't going to be an excuse — I've been building my own preparation track instead: structured DSA practice, a growing comfort with C++, and enough web development to actually ship things rather than just read about them.

That self-directed approach is also why this site exists. Writing a daily note on a DSA problem or a programming concept forces me to actually understand it instead of just recognising it — and if it helps another student stuck on the same problem, even better.

Longer-term, I'm working toward two goals in parallel: cracking NIMCET for an MCA seat at an NIT, and building a strong enough portfolio to compete for product-company placements despite having no campus pipeline to rely on.

The journey so far

Foundations

C and the basics of programming logic

Started with C in the first year — control flow, functions, pointers, arrays — the groundwork everything else builds on.

Going deeper

DSA, C++ and the transition from C

Moved into C++ and started Data Structures & Algorithms properly — arrays, linked lists, vectors, binary search, merge sort — following structured resources like Striver's A2Z and Love Babbar's sheet.

Building in public

KP Study Hub and this site

Started building tools for myself and other students — study trackers, concept maps, and now a proper place to write daily notes instead of letting them sit in a notebook.

What's next

NIMCET prep and placement-ready portfolio

Working through maths and aptitude for NIMCET while keeping the DSA practice consistent enough to be interview-ready whenever the right opportunity shows up.
